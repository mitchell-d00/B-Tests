attachments, current MPLPB docs, existing B-Tests papers and two linked public
author repositories. Missing available editions are copied unchanged. Existing
byte-identical files are indexed in place, with no original deleted or overwritten.
Distinct editions remain distinct; copies are not independent research results.

## Source identity and remaining availability gaps

[Original paths, pinned revisions, Git blob identities and SHA-256](manifest.json)
provide the reverse map. Copied papers retain original relative links; follow
the recorded source repository/path when a relative link depends on that context.
Ben's third-party PDFs are cited by source hashes in the study, not republished
as Mitchell-authored works. No old file is renamed as a new result.

This is not a claim to contain every Mitchell paper ever published. The following
known titles were found in public indexes, but their pages returned HTTP403 during
this acquisition; no PDF, full-text content or content hash is fabricated:

- [I Build Like I Am Dead](https://philarchive.org/rec/MCPIBL) — not acquired; HTTP403.
- [A Bridge Language Is Tested by Load](https://philarchive.org/rec/MCPABL) — not acquired; HTTP403.
- [The Dual-System Architecture](https://philarchive.org/rec/MCPTDA) — not acquired; HTTP403.

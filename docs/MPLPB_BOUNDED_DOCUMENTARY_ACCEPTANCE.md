# Pinned MPLPB documentary acceptance

The [workflow](../.github/workflows/bounded-documentary-acceptance.yml) runs
Combined MPLPB at an exact revision. It checks compound fields, alias collisions,
source-state changes, correction scope, evidence budgets, and communication
candidates. It then gives the existing isolated D% worker the original public
packets and checks the native output after execution.

The replay must preserve the previous complete answers and all 580 expected
refusals. For each newly supported compound question, it checks both field
quotes and their source spans. Remaining unanswered families stay visible in
the report. The workflow publishes counts by family, a run receipt, and failure
logs. The public source text supplies the two literal field lines for the new
checks. The private custodian key never enters the worker.

This is an MPLPB development replay. The separate historical replay runs in
Combined MPLPB's acceptance workflow. Independent semantic review and native
OOCC execution remain unrun in this comparison.

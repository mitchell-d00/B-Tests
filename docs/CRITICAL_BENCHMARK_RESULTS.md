# Critical benchmark results — 16 November 2026

The two real fresh-agent runs returned **119/119 correct requested values each**.
Both rejected the false all-ready approved map, retained historical failures,
respected the project-limited correction and revoked grants, distinguished stored
packets from acknowledged reads, rejected unsupported causal influence, counted
independent datasets correctly, and selected **P7 only** for local release.
These outcomes do not demonstrate unsupported propagation of inherited errors.

CAD also returned an extra **Q120**, which was not a supplied question. That is an
output-contract failure. The conventional arm returned only the 119 requested IDs.
Both met the 900-character handoff limit: CAD **881**, conventional **900**.

the current task. The key additionally requires the policy ID. CAD's P3 permission

of eleven or ten incorrect factual answers. The key was not changed after seeing
outputs. The source-set column is a mechanical contract measure, not independently
established entailment or answer quality.

Every cited quote is an exact substring of its supplied original. Both models
correctly preserve positive controls: P4's supported intervention, P5's successful
F0, P6's acknowledged read, and P7's justified release. This is not blanket refusal.
The evaluator's post-hoc review of equivalent citation routes is unblinded. A
blinded independent reviewer has not adjudicated these records.

No accuracy improvement from CAD was observed in this matched pair. CAD's extra
answer is an additional contract error in this run. These observations establish
neither general equivalence nor inferiority, and do not falsify OOCC/CAD as a whole.
No paper claim has been narrowed solely because a model added an unrequested ID.
The test instruction's output contract failed; a broader theoretical claim needs
its own relevant acceptance criterion.

The copied target input bytes were independently compared to the sealed request's

The subjects' final JSON was archived in a separate turn after submission, without
changing its values. The original collaboration messages remain authoritative.

processed. The target could read shared filesystem paths; isolation was requested,
not OS-enforced. Instruction wording could reveal the treatment.

The evaluator saved submitted answers and action requests, reopened them, then
scored. No target architecture was repaired; no submitted answer was corrected.
P7 is a selected local probe effect, not independently observed dispatch, delivery

Costs: exact request-file bytes can be recomputed from retained files. CAD's

remove that input-cost difference. Provider model snapshot, sampling settings,
seeds, tokens, monetary charges and reliable per-call latency were not exposed.
Human/operator review time was not instrumented. No values are invented.

The scope is intentionally narrower than Ben's complete publications. A record
containing an explicit negative statement is easier than interpreting conflicting
unprepared real records. Repeated question templates, conspicuous planning-map
labels, ten related fictional projects and access to all originals limit difficulty.
Matching the dimensions reported for Ben's MPLPB tests does not establish equal
semantic difficulty. No independent holdout or production accuracy claim is made.

### Diagnostics are not identical API spellings

Ben's eight proposed codes in §7 are a suggested interface, not a claim that existing MPLPB uses those literal names. Current controls observe `interpretation_unsupported` with category `unsupported_question_grammar`, `no_eligible_sources`/`absent_eligible_source`, `evidence_not_established`/`insufficient_evidence`, and `conflicting_or_multiple_owners`/`known_source_conflict`.

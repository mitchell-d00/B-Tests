# Testing OOCC — M6 attribution correction

20 November 2026. Corrected in version 1.3.

Version 1.2 mistakenly referred to “McPhetridge's private M6.” That attribution
was introduced during preparation of this review and is withdrawn. It is not a
claim from McPhetridge's first response.

McPhetridge built MPLPB and B-Tests. According to his clarification, M6 is an
additional component Gelhaus adds. It is not included in the supplied public ZIP;
its implementation and exact execution role could not be inspected or reproduced
from that package. The public reproduction script invokes MPLPB's modules.

The original response already states the absence and verification limit at PDF
pages 2 and 7. The newly supplied response.pdf is byte-identical to the
[archived first response](../papers/archive/field-access-response/response.pdf):
SHA-256 `9f1ba62c4425f29af7908a5736e3f6c0c84bce05f30909fdc1a4b3a9dafcdb16`.
That paper does not claim M6 was independently run or establish its original role.
The current clarification is attributed to McPhetridge; it is not a new audit of
M6 or evidence of its private execution.

Version 1.2 is preserved unchanged for the historical record. Its superseded
wording must not be used as current attribution. No benchmark scores, underlying
source documents or prior experimental outputs change as a result of this erratum.
